# APPOINTMENT BOOKING SYSTEM

A secure, role-based appointment booking web application that simplifies scheduling, service management, and user administration for both users and administrators.

---

## 📌 Features

### 🔐 User Authentication
- User & Admin login
- Secure password hashing
- Forgot password & reset via email

### 📅 Appointment Management
- Book appointments based on available services
- Slot availability management
- View appointment history

### 🧑‍💼 Admin Dashboard
- Manage users
- Add, edit, delete services
- Manage service slots
- View and control appointments

### 📧 Email Notifications
- Password reset emails using PHPMailer  
- (Configured with dummy credentials for security)

### 🎨 Modern UI
- Responsive design
- AJAX-based interactions
- Clean and user-friendly interface

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP (Core PHP)
- **Database:** MySQL
- **Mailer:** PHPMailer
- **Version Control:** Git & GitHub

---

## 🚀 Getting Started

### Prerequisites
- XAMPP / WAMP / LAMP
- PHP 7.4+
- MySQL
- Web Browser
- Composer (optional, if required)

---
Install XAMPP, clone or download the project into the htdocs folder, 
create a MySQL database named `appointment_system`, import the provided SQL file, 
update database credentials in `config.php` if required, 
and run the project using http://localhost/Appointment_Booking_System/.
